# Chacra Don Andres - Web Experience & Tour 360

Sitio web oficial y plataforma digital interactiva para Chacra Don Andres (Las Piedras / Montevideo Rural, Uruguay).

## Como iniciar localmente
- En Windows: Doble clic en `run_server.bat`
- En Mac/Linux: `./run_server.sh`
- Con Python: `python serve.py`
